# 英语跟读评分 Demo

一个纯前端的英语跟读评分应用。输入英文句子 → 听示范朗读 → 跟读录音 → 自动识别并给出评分。

> 面试前实践任务，跑通核心流程为目标，无需后端、无需 API Key、零依赖。

## ✨ 核心功能

- **示范朗读**：浏览器原生 TTS，支持美式/英式发音、女声/男声切换、语速调节，朗读时逐词高亮
- **跟读录音**：MediaRecorder 录音，实时音量条、计时、录音回放
- **实时识别**：Web Speech API 边说边转写（实时字幕）
- **智能评分**：词级 Levenshtein 对齐，输出 0-100 得分、单词正确率、WER 词错率，以及逐词对比（读对 / 读错 / 漏读 / 多读）
- **环境自检**：自动识别浏览器能力，给出明确的使用指引

## 🛠 技术栈

| 环节 | 技术 |
|---|---|
| 朗读 (TTS) | `SpeechSynthesis`（浏览器原生） |
| 录音 | `getUserMedia` + `MediaRecorder` |
| 音量分析 | `AudioContext` + `AnalyserNode` |
| 语音识别 (STT) | `webkitSpeechRecognition` |
| 评分算法 | 词级 Levenshtein 动态规划（纯 JS，离线运行） |
| 前端 | 单 HTML 文件，原生 CSS + JS，无框架无依赖 |

## 📖 使用流程

1. 在文本框输入英文句子（或点击示例）
2. 选择发音口音（美式/英式）和音色性别（女/男），点击 **🔊 朗读句子** 听示范
3. 点击 🎙 麦克风按钮，允许麦克风权限后开始跟读
4. 跟读完再次点击麦克风停止，自动出分

## 🧮 评分算法

1. **归一化**：原句和识别文本都转小写、去标点、按词切分
2. **词级对齐**：用 Levenshtein 动态规划计算最小编辑路径，回溯得到逐词操作
3. **四类错误**：
   - `equal` — 读对（绿色）
   - `sub` — 读错，原词 vs 识别词成对显示（红色划线 + 橙色）
   - `del` — 漏读（红色虚线）
   - `ins` — 多读（灰色）
4. **得分** = 读对词数 / 原句词数 × 100
5. **WER** = (替换 + 漏读 + 多读) / 原句词数

## ⚠️ 已知边界

- 评分基于语音识别文本与原句的词级对齐，衡量"读得对不对、全不全"，**不等同于专业发音分**（不评估音素准确度、流利度、语调）
- 同义替换、缩写差异（如 `can't` vs `cannot`）会被判为不一致
- 识别准确率受麦克风和环境噪音影响
- 部分环境（IDE 内置预览窗口）不支持麦克风，请用系统浏览器打开
